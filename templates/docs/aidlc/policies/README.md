# Policy skills

Your organization's rules, written as skills so agents apply them consistently: security standards, API conventions, brand, UX, compliance.

Each policy has a named owner and a written source of truth. Create one with the `/aidlc-policy-skill` skill, starting from `docs/aidlc/templates/policy-skill.md`.

| Policy skill | Owner (role) | Source of truth | Backed by a guard check? |
|---|---|---|---|
| | | | |

A skill is advisory. For any rule that must always hold, add a guard check (`/aidlc-guardrails`) or a review pass.
