# Coding standards

Baseline coding standards used by AI code review and by people. One Markdown document per language or framework, with rule IDs and default severities, so every review finding can cite the exact rule.

These are written from general industry practice as a starting point. Your language owners should review and adapt them, record local overrides in each document, and approve changes through pull requests.

See [index.md](index.md) for the language list, how documents are chosen, and how to add a new one.
